Local APIs you can use in your own scripts

Everything below is served by Milelik on this device. Send the connection token in the X-Milelik-Token header. The OpenAPI description is at /api/openapi.json.

curl -H "X-Milelik-Token: YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"expression":"sqrt(3^2+4^2)"}' \
  http://127.0.0.1:8765/api/math/evaluate

Recommended

Leave auto-approve off until you trust your model and setup. You can approve each action in this browser instead of switching back to a terminal.

🧰 Front end and workspace

Keep 127.0.0.1 unless you intentionally want LAN access. Web address changes apply next time the front end starts.
